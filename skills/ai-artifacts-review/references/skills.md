# Skill Files Audit Checks

Skill format should be compatible across VS Code, Cursor, and Claude. References:

- [VS Code Agent Skills](https://code.visualstudio.com/docs/copilot/customization/agent-skills)
- [Cursor Agent Skills](https://cursor.com/docs/skills)

For each `SKILL.md`, check:

| Code | Check                                           | Rule                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
|------|-------------------------------------------------|----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| FM02 | `description` discoverable                      | Required. Must answer both *what* and *when*. Must start with "You should use this skill ..." followed by a concise description of conditions/scenarios when the skill should be invoked                                                                                                                                                                                                                                                                                                                                                                                   |
| FM03 | `argument-hint` present                         | Required when the skill accepts arguments. At most 7 words                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
